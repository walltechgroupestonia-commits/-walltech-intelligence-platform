# Walltech Intelligence Platform

## Purpose

Walltech Communication Intelligence is the operational layer that connects:

Aruba Mailboxes
→ Communication Intelligence
→ CRM
→ Production Statistics
→ Revenue / Income Evidence

## Initial Scope

### Mail
- Read operational mailboxes hosted on Aruba via IMAP
- Send approved communications via SMTP
- Track inbound and outbound communication cycles
- Detect unanswered messages
- Extract deal-related evidence from email threads

### CRM
- Route qualified communications to HubSpot
- Link messages to leads, contacts, companies and deals
- Record next action, owner, deadline and evidence

### Reporting
- Campaign activity
- Leads
- Qualified conversations
- Deal progression
- Time To Revenue
- VFP exchanged
- Fee maturity
- Invoice
- Income
